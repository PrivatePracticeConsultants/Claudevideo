# Reusable prompts

The prompts from the pack that **cannot be run without the live instance**,
kept here so they are pasted with this repo's context attached rather than
retyped from memory.

| File | When |
|---|---|
| `00-connect.md` | Once, before anything else. Nothing below works until it does. |
| `02-taxonomy.md` | Once, after the first devices are paired. |
| `04-add-device.md` | **Every time hardware arrives.** The one you reuse forever. |
| `11-voice.md` | Once, when setting up Assist. |
| `14-audit.md` | **Monthly.** |
| `15-debug.md` | Whenever something misbehaves. |
| `16-upgrade.md` | **Before every HA update.** HA ships monthly and breaks things. |
| `17-hardening.md` | Once, then re-audit via `14`. |
| `18-radio.md` | **Before pairing the first batch.** Then on demand for mesh health. |
| `19-people.md` | Per person. |
| `21-tablets.md` | Per wall tablet. |

Prompts 01, 03, 05–10, 12, 13 and 20 are not here: they are already **built**.
See the packages, dashboards, scripts and CI in this repo.
